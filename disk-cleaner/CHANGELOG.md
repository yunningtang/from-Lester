# 更新记录

## 0.4 — 整理和撤销

- 重复文件：大小 → 开头结尾 → 完整哈希三步确认；每组留一份，可以改留哪一份。
- 整理下载和桌面：截图、录屏按月份收好；很久没碰的东西收进“归档”。
- 挪到别的盘：你的文件可以挪到 D 盘或移动硬盘；跨盘时复制后逐字节核对，才删除原来那份。
- 撤销：挪走和整理的可以一键放回原处，也可以在“清理记录”里撤销某一批；不覆盖任何文件，空文件夹一起清掉。
- “很久没用”改为只看修改时间。

## 0.3 — 新界面

- 界面换成 pywebview：无边框窗口、透明标题栏，整个窗口是一张宣纸上的水墨。
- 看看里面：能重新生成的文件夹、重复的副本、安装包、系统镜像、已经解压过的压缩包、很久没改动的下载。
- 识别 iPhone 备份、WSL / Docker / 虚拟机磁盘、Steam；页面文件和休眠文件单独列出。
- 新增 Firefox、微信、Teams、VS Code、缩略图、错误报告、Gradle 等缓存。
- 清理记录页。

## 0.2 — 安全

- 删除前先检查能不能进回收站（本地磁盘、回收站开着、放得下），放不进去就不删。
- 删除分两步：只读预检 → 确认 → 逐项再查一次。
- 个人文件夹本身、OneDrive、链接一律不删；缓存目录要通过合理性检查；扫描后有变化的文件不删。
- 界面不再说“已释放”：移到回收站后，清空回收站才会腾出空间。
