# 使用说明

## 打开以后

留白会先扫描系统盘（通常是 C 盘），大约需要几十秒到两分钟。扫描只读文件大小，不会改动任何东西。扫描时墨块会一块块长出来，左上角写着正在看哪里。

## 全貌

左边的纸上从上到下是：

1. **磁盘**：哪个盘、多大、用了多少。
2. **留白**：现在还有多少可用空间。
3. **一句话**：现在怎么样、接下来可以做什么。
4. **可放心清理**：缓存和临时文件，按四组列出（系统临时文件、浏览器缓存、聊天和办公软件、开发工具缓存）。点一组的名字整组选上或取消；点“展开”看每一项是什么、清了会怎样。微信缓存、Gradle 缓存和旧安装包默认不选。
5. **值得看看**：要你来决定的事——重复文件、整理下载、整理桌面，以及占得最多的几块你的文件。
6. **回收站** 和 **墨色图例**。

右边的画：

- 每一块墨是一类文件，面积按大小，墨色分五级：40 G 以上、20–40 G、8–20 G、3–8 G、3 G 以下。
- 鼠标停在墨上会说明它是什么；点浅色的缓存块直接选上或取消；点其他块看里面。
- 右上角的最小化、最大化、关闭按钮会跟着底下墨色的深浅变色。

## 看看里面

点开一块你的文件（比如“下载”），会列出：

| 分组 | 是什么 | 能做什么 |
|---|---|---|
| 可能不再需要 | 已经解压过的压缩包、安装包、系统镜像、重复的副本、能重新生成的文件夹、很久没改动过的下载 | 移走（到回收站），或者“留着”——以后不再提醒 |
| 你的文件 | 自己拍的视频、照片、文档 | 挪到别的盘（如果有） |
| 最近还在用 | 最近改动过的 | 只看 |
| 留白不会动 | 聊天记录数据库、源代码等 | 只看 |

“很久没用”只看文件的修改时间。Windows 常常不记录“打开时间”，所以一部电影两年前下载、上周还看过，也可能被列进来——它只是建议，要不要移走由你决定。

程序、系统、回收站这几块点开后只有说明：程序请在 Windows 设置里卸载；系统文件交给 Windows 自带的“存储感知”；回收站留白不替你清空。

## 重复文件

内容一模一样的文件按组列出，每组标出“留下”的那一份。默认留：图片 / 文档 / 视频里的 > 桌面 > 下载 > 微信 / QQ 里的；同样位置的留最早的那份。

- 点副本前面的“移走”选上；“选上所有副本”一次全选。
- 想留另一份，点“改留这份”。
- 留下的那份不会被移走；即使同一组全部选上，也会留一份。

## 整理下载和桌面

- **截图和录屏**：收进 图片 › 截图、视频 › 录屏，按年月分好。
- **下载里 30 天没碰过的东西**：收进 下载 › 归档 › 年-月。
- **桌面上 90 天没碰过的文件**：收进 桌面 › 归档 › 年-月。桌面上的文件夹和快捷方式不动。

整理只是挪位置，不删除。正在下载的文件、隐藏文件、快捷方式都不会动。

## 挪到别的盘

电脑上有 D 盘或插着移动硬盘时，“你的文件”下面会出现“挪到 D 盘”。文件会放到 `D:\留白挪出\类别\原来的路径`。跨盘要复制一遍，复制完逐字节核对一致，才会删掉原来那份。

## 每一步动手之前

点“移到回收站”“整理”“挪走”后，按钮会原地变成一段说明：要动什么、多大、什么不会动以及为什么、要注意什么。点“确定”才开始；点“再想想”或按 Esc 取消。

## 撤销

- **挪走和整理的**：做完后直接点“撤销”；以后也可以在“清理记录”里撤销某一批。撤销时，原来的位置如果已经有了新文件，那一项不放回，不会覆盖任何东西。整理时新建的空文件夹也会一起清掉。
- **移到回收站的**：打开回收站，右键“还原”。

## 为什么移到回收站后可用空间没变多？

文件只是换了个地方，还在同一个盘上。清空回收站以后，空间才会真正空出来。留白不替你清空，因为清空了就找不回来了。

## 常见问题

**有些项目显示“没有动”？** 通常是文件正在被使用（比如浏览器开着时的缓存），或者扫描之后文件有变化。关掉对应的程序，重新扫描再试。

**清理记录存在哪？** `%LOCALAPPDATA%\Liubai\logs`，每天一个文件，每一项一行。

**能清理别的盘吗？** 现在只看系统盘。
