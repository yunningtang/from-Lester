# 莱斯特释放学堂

根据 `pdf/莱斯特教导合集中文版` 全书（509 页，11 个合集，190 节）生成的可教学、可实践的静态网页。

打开 `site/index.html` 即可使用（也可用 GitHub Pages 发布 `site/` 目录）。

- **课程**：按原书顺序逐节学习：概述、核心要点、原文金句（逐字校验过）、练习、自测题、笔记、完整原文
- **释放工作台**：看见感受（AGFLAP）→ 辨认“想要”（认同 / 控制 / 安全）→ 放下 → 回看，自动记录
- **练习库 / 随机自测 / 全文检索 / 概念与金句 / 我的记录**
- 进度与记录只保存在本机浏览器（localStorage）

`tools/` 下是从 PDF 提取、切分章节、合并提炼内容并生成 `site/data/*.js` 的脚本。
