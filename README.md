# 莱斯特释放学堂

根据 `pdf/莱斯特教导合集中文版` 全书（509 页，11 个合集，190 节）生成的可教学、可实践的静态网页。

打开 `site/index.html` 即可使用（也可用 GitHub Pages 发布 `site/` 目录）。

## 结构

- **今天**：每日清单（30 天实践当天、下一课、到期复习、释放一次）、连续天数、今日原话、情绪层级
- **学习**：全书 190 节按主题重编为 10 个单元（莱斯特是谁 → 释放的基本方法 → 想要自由与抗拒 → 对死亡的恐惧 → 爱与关系 → 心智、责任与业力 → 身体与健康 → 欲望、目标与创造 → 生活中的应用 → 我是谁与终极状态），每单元有学习目标，分必读与选读
  - 每一课全屏逐步走（和释放流程同一种交互）：概述 → 要点 → 读原文 → 莱斯特原话 → 检验一下 → 练习 → 记笔记 → 完成
  - 原文阅读器：像书一样分页，点按左右、滑动或方向键翻页；显示页码、本节与全书进度；可调字号、看目录；记住读到哪里；读完一节可回到课程或翻到下一节
  - 笔记（Coursera 式）：在阅读器里选中文字即可划线或写笔记，笔记锚定到原文段落；“我的笔记”按单元与课程分组，可搜索、筛选、编辑、删除、复制，并能一键跳回原文位置
  - 间隔复习：学过的题在 1、3、7、14、30 天后回来，答错回到第 1 天
  - 工具：全文搜索、练习库、概念与原话、原书目录（按原书顺序阅读）
- **30 天**：按莱斯特 1952 年心脏病后实际走过的顺序设计的每日实践
- **释放**（依据原书的方法）：
  - 三种入口：一个感受 / 卡住或说不清 / 一件想要的事（“任何你想要的东西，都通过释放来得到它”）
  - 看见：情绪词表（参考 1992 年圣多纳课程的情绪表整理，约 90 个词，可搜索）帮你说出此刻的感受，并给强度打分（0–10）
  - 辨认：三大想要各有一组自问句和常见念头（提示词），并标出该层感受常见的想要；看不清就释放“想要改变这个感受”
  - 放下：一轮一轮放下，可随时切换底下的想要；卡住时释放想要改变卡住的感受；认同与控制放下几轮后，提示往下看对死亡的恐惧（想要安全）
  - 释放干净：回看时还剩几分，就提示“想要＝没有”，一键继续放到 0
  - 回看：再打分，看到强度变化，记录放下了哪些想要；“我的”里汇总最常出现的感受、最常放下的想要和平均减轻幅度
- **持续释放**：工作、走路、做家务时开着，觉察到想要就点一下放掉；计时计入当天释放时间，显示占清醒时间的比例（目标 50%）；可设每 5/10/15/30 分钟轻声提醒“此刻，有想要吗？”；目标按莱斯特说的节奏逐步加：1 小时 → 早晚各 1 小时 → 几个小时 → 半天 → 一整天
- **我的**：连续天数、统计、8 周日历、反思、记录与笔记

进度与记录只保存在本机浏览器（localStorage）。所有“原话”都经程序与原文逐字核对；概述、要点、练习、题目、单元编排与 30 天计划为 AI 根据原文整理。

`tools/` 下是从 PDF 提取、切分章节、合并提炼内容并生成 `site/data/*.js` 的脚本；`tools/curriculum.json`、`tools/plan.json` 是课程编排和 30 天计划。

## 释放随身（独立工具）

`release-tool/` 是一个单独的、全天随手用的释放工具（一个文件，不依赖全书数据，打开很快）：

- **释放**：情绪词可多选，一起释放；一键放掉“想要被认同 / 想要控制 / 想要安全 / 想要改变它”；“持续释放”计时计入当天释放时间（目标可按 1 小时 → 一整天逐步加，显示占清醒时间的比例）；按设定间隔轻声提醒“此刻，有想要吗？”，可直接在提醒里点掉；中间的球打开完整引导：情绪词 → 三大想要提示词 → 一轮轮放下（卡住、往下看一层）→ 还剩几分，继续放到 0
- **识别**：三大想要的自问句与常见念头、情绪表（参考 1992 年圣多纳课程整理），点词直接开始释放
- **记录**：近 7 天释放时间、累计放下次数、平均减轻、最常放下的想要与最常出现的感受、今天的时间线
- **设置**：外观（自动 / 浅色 / 深色，主页右上角也可一键切换）、触感反馈开关、提醒间隔、每日目标、清醒时长
- **玻璃质感**：背后是缓慢流动的柔和色彩，卡片、按钮、底栏与引导页都是半透明毛玻璃（带高光边缘），深色模式为深青蓝色调
- **iOS 风格**：无分割线的分组卡片、毛玻璃底栏与提醒、分段控件与开关；所有点按有缩放回弹，安卓按动作区分震动强度，iPhone（iOS 18+）用系统开关的触感
- 名言区轮换 162 句与释放相关的莱斯特原话（均与原文逐字核对）

用 GitHub Pages 发布后可“添加到主屏幕”像 App 一样使用（含 manifest 与离线缓存）。修改 `release-tool/app.html` 后运行 `python3 tools/build_release.py` 生成 `index.html`。
