# 莱斯特释放学堂

根据 `pdf/莱斯特教导合集中文版` 全书（509 页，11 个合集，190 节）生成的可教学、可实践的静态网页。

打开 `site/index.html` 即可使用（也可用 GitHub Pages 发布 `site/` 目录）。

## 结构

- **今天**：每日清单（30 天实践当天、下一课、到期复习、释放一次）、连续天数、今日原话、情绪层级
- **学习**：全书 190 节按主题重编为 10 个单元（莱斯特是谁 → 释放的基本方法 → 想要自由与抗拒 → 对死亡的恐惧 → 爱与关系 → 心智、责任与业力 → 身体与健康 → 欲望、目标与创造 → 生活中的应用 → 我是谁与终极状态），每单元有学习目标，分必读与选读
  - 每一课全屏逐步走（和释放流程同一种交互）：概述 → 要点 → 读原文 → 莱斯特原话 → 检验一下 → 练习 → 记笔记 → 完成
  - 原文阅读器：像书一样分页，点按左右、滑动或方向键翻页；显示页码、本节与全书进度；可调字号、看目录；记住读到哪里；读完一节可回到课程或翻到下一节
  - 笔记（Coursera 式）：在阅读器里选中文字即可划线或写笔记，笔记锚定到原文段落；“我的笔记”按单元与课程分组，可搜索、筛选、编辑、删除、复制，并能一键跳回原文位置
  - 间隔复习：学过的题在 1、3、7、14、30 天后回来，答错回到第 1 天
  - 工具：全文搜索、练习库、概念与原话、原书目录（按原书顺序阅读）
- **30 天**：按莱斯特 1952 年心脏病后实际走过的顺序设计的每日实践
- **释放**（依据原书的方法）：
  - 三种入口：一个感受 / 卡住或说不清 / 一件想要的事（“任何你想要的东西，都通过释放来得到它”）
  - 看见：选 AGFLAP 中的感受并给强度打分（0–10）
  - 辨认：用三个自问分辨想要被认同 / 想要控制 / 想要安全；看不清就释放“想要改变这个感受”
  - 放下：一轮一轮放下，可随时切换底下的想要；卡住时释放想要改变卡住的感受；认同与控制放下几轮后，提示往下看对死亡的恐惧（想要安全）
  - 回看：再打分，看到强度变化，记录放下了哪些想要；“我的”里汇总最常出现的感受、最常放下的想要和平均减轻幅度
- **我的**：连续天数、统计、8 周日历、反思、记录与笔记

进度与记录只保存在本机浏览器（localStorage）。所有“原话”都经程序与原文逐字核对；概述、要点、练习、题目、单元编排与 30 天计划为 AI 根据原文整理。

`tools/` 下是从 PDF 提取、切分章节、合并提炼内容并生成 `site/data/*.js` 的脚本；`tools/curriculum.json`、`tools/plan.json` 是课程编排和 30 天计划。
